# EduPsych CRM — Installers | קבצי התקנה

**English** · [עברית](#עברית)

EduPsych CRM is a clinic-management system for educational psychologists: clients, sessions, documents and backups, with encrypted data kept on your own device. Available for Windows and Android.

- ⬇️ **Download:** [latest release](../../releases/latest)
  - **Windows:** `EduPsychCRM-Setup-<version>.exe` (installer, updates automatically) or `EduPsychCRM-Portable-<version>.exe`
  - **Android:** `EduPsychCRM-<version>.apk` (checks for updates on every launch)

### Installing on Android
1. Open the release page **on your phone** and download the APK.
2. Open the file; if prompted, allow your browser to "install unknown apps".
3. Tap **Install**.

Your data stays on your device and is never erased by an update. This repository contains installation files only; the source code is private.

EduPsych CRM – קליניקה חינוכית: מערכת לניהול קליניקה לפסיכולוגים חינוכיים – מטופלים, פגישות, מסמכים וגיבויים, והנתונים נשמרים מוצפנים במכשיר שלך. זמינה ל־Windows ולאנדרואיד.

### התקנה באנדרואיד
1. פותחים את עמוד הגרסה **בטלפון** ומורידים את קובץ ה־APK.
2. פותחים את הקובץ; אם הטלפון מבקש, מאשרים לדפדפן "התקנת אפליקציות ממקורות לא ידועים".
3. לוחצים **התקנה**.

הנתונים נשמרים במכשיר ואינם נמחקים בעדכון. המאגר מכיל קבצי התקנה בלבד; קוד המקור פרטי.
