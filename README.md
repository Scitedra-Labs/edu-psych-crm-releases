# קליניקה חינוכית — EduPsych CRM: קבצי התקנה

המאגר הזה מכיל **קבצי התקנה בלבד** (Windows ו-Android). קוד המקור אינו נמצא כאן.

- **Windows:** הורידו את `EduPsychCRM-Setup-<גרסה>.exe` מעמוד [Releases](../../releases/latest) והפעילו אותו. התוכנה מתעדכנת אוטומטית.
- **Android:** הורידו את `EduPsychCRM-<גרסה>.apk` מעמוד [Releases](../../releases/latest). האפליקציה בודקת עדכונים בכל הפעלה.

הנתונים שלכם נשמרים במכשיר ואינם נמחקים בעדכון.
